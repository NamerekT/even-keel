Часть карты BTN-732, решения от 06.11.2026. За основу — текущая карточка задачи (`TaskCard.tsx`). У встроенного трекера кнопка «Open in Huly» в шапке не нужна: карточка сама место правки.

## Поля

- **Заголовок** — правка на месте по нажатию. Enter сохраняет, Esc отменяет, пустой не сохраняется.
- **Статус** — выпадающий список из 7 фиксированных (BTN-767). Ручная смена идёт через уже существующие действия: Done по задаче в работе — исключение «task in Done», в Backlog — как «To the backlog».
- **Веха** — выпадающий список с «Создать веху \"…\"» по введённому имени. Веха, которую не пускает «Project tasks» проекта, выбирается, но с подсказкой.

## Связи

- Отказы с причиной под полем: связь с собой; повтор существующей; `blocks`, который замкнёт цикл; блокер в более поздней вехе (`docs/chain/entry.md`).

## Родитель и подзадачи

- **Задача с родителем** — в правой колонке поле «Parent» со ссылкой. Сменить или снять родителя — поиск по задачам **своего** проекта. Отказ: сама задача, её потомок (цикл).
- **Первая подзадача у задачи в работе.** Перед созданием — подтверждение: «Задача BTN-… сейчас в работе».

## Конфликт правок — без ложных срабатываний

- Сравнение **по полям**, не по версии всей задачи. Правка уходит как «поле X было A, стало B»; сервер отказывает, только если X сейчас уже не A.

# Page: the project page

Bare task numbers in card descriptions, comments and journal entries open the referenced card through the same action as a relation. The Markdown plugin in `cardTaskRefs.ts` recognizes whole task numbers using the live project prefixes and each feed's effective prefix. The chat's task panel shares the renderer. Code, existing links and addresses retain their Markdown behavior.

## Subtopics

The area is split by subtopic, a file each in `docs/web/project-page/`: read this table, then the whole file of your subtopic. A new section goes into the file of its subtopic; a new subtopic is a new file and a row here. Keep a file under ~30 KB, so that it is read whole.

| File | What is in it |
| --- | --- |
| [`task-card.md`](project-page/task-card.md) | The task card: editing, subtasks, the journal, the description editor, drafts, attachments, adding tasks |
| [`head.md`](project-page/head.md) | The changelog of a milestone, the project head, the Chats tab, the Legend |
| [`chain-and-backlog.md`](project-page/chain-and-backlog.md) | Links on a chain row, folding, long milestones, entry into the chain, the backlog's order and search, the lamp, the feed's views, parents |
| [`motion.md`](project-page/motion.md) | Motion of changes, the glide of a new order, the "Under way" group, the side column, the meme |

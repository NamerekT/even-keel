# Page: the session panel and the chat

The area is split by subtopic, a file each in `docs/web/session-panel/`: read this table, then the whole file of your subtopic. A new section goes into the file of its subtopic; a new subtopic is a new file and a row here. Keep a file under ~30 KB, so that it is read whole.

| File | What is in it |
| --- | --- |
| [`panel.md`](session-panel/panel.md) | A starting session, the session's facts and account pills, the chat with the current session (the feed, the open question, the reply's lock, the draft, one window per task), the chat's task panel, the window's frame and head |
| [`composer.md`](session-panel/composer.md) | The composer: the status line and the context ring, the box, dictation, files, the field on a phone, banners over the field, commands and the menu's items |
| [`media.md`](session-panel/media.md) | Calls in the chat, the compaction divider, pictures in the transcript and the viewer, videos the user sent, files a session sends |
| [`turn.md`](session-panel/turn.md) | The turn line and its delivery phase, the delivery mark, mail to a working session, the message menu, following the feed's end, the live transcript window, `/api/session/answer` |

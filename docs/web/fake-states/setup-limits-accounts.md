The URL parameters of the wizard, context and cache, limits, branches, the config, CI, packages, trackers and accounts.

| Parameter | What it shows |
| --- | --- |
| `?projects=none` | no projects yet: the home page sends to the wizard; with `&tally=none` it is the first run, and it sends to the setup `/setup` |
| `?wizard=untrusted\|off\|failed\|templates` | the wizard's check (`web/src/live/fakeProjects.ts`): the folder is not trusted; the tracker has no variables; the tracker does not answer; an issue template of the folder puts on the required label "bug", on any tracker so that the default one shows it (BTN-1130).

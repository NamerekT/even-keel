# Сессии, модели, промты, лимиты

Справка для сессий: как Even Keel запускает `claude` и следит за ним.

## CLI и транскрипты

- Сессии — CLI `claude` (`--bg`, `agents --json`). Бинарь: `EVEN_KEEL_CLAUDE_BIN`, иначе отдельный CLI `~/.local/bin/claude.exe` (вне Windows — `claude`), иначе бинарь самой свежей версии расширения VS Code (его папку обновление расширения удаляет).
- Транскрипты — в `<папка аккаунта>/projects`. `claude agents`, транскрипты, `sessions/<pid>.json` и `settings.json` читаются по каждой папке аккаунта.
- `claude agents --json` (2.1.284) не печатает ни `pid`, ни `status`, а `state: done` остаётся и за живой сессией после хода, и за остановленной: живой процесс, `pid` и `busy`/`idle` дают записи `sessions/<pid>.json` с живым `pid` (`withLiveRecords`).
- Свежесть кэша промпта — из транскрипта: срок (5 мин или 1 ч) по `usage.cache_creation` последнего ответа, который писал кэш (оба — берётся 5 мин), отсчёт от первой строки последнего ответа.
- `claude --bg` ходит через демон-супервизор (`claude daemon run`, на Windows канал `\\.\pipe\cc-daemon-…`). Остановка службы фоновые сессии не убивает — они дети демона.

## Модель (`src/sessions/launch.ts`)

По ярлыку задачи `Sonnet`/`Opus`/`Haiku` (без регистра и пробелов по краям): `--model <алиас>` на каждом запуске — первом, `--resume`, передаче дел, «Новой сессии»; к промту дописывается `modelPrompts.<алиас>` из `even-keel.config.json`, если есть. Нет ярлыка или их два разных — модель по умолчанию, второе — с предупреждением в лог.

## Промты (`src/sessions/prompt.ts`)

Собираются строго: значение в промте запуска и передачи дел — через `fill`, пустое или не строка — ошибка сборки, цепочка встаёт на паузу с ней, а не уходит в сессию с пустым местом. `modelPrompts` передаётся как есть, подстановок в нём нет: `{имя}`, `{{имя}}`, `${имя}` — ошибка конфига. Язык промтов — `promptLanguage` (`src/chain/prompts.ts`, см. `docs/web.md`).

## Лимиты

- У каждого аккаунта свои: `claude -p /usage --output-format json --no-session-persistence` в его папке раз в 5 минут (локальная команда, квоту не тратит) и снимок statusline (он помечен `configDir` сессии, без пометки — глобальный аккаунт); берётся более свежий.
- Чаще не опрашивать: сервер отвечает на `/api/oauth/usage` 429, его же опрашивает панель расширения VS Code тем же токеном, а CLI (2.1.286) после 429 не спрашивает этот токен ~45 мин.
- С истёкшим access-токеном или после 429 `/usage` лимитов не отдаёт (строка подписки есть, строк окон нет) — это «нет данных» (`stale`), не ошибка. Ответ `/usage` принимается целиком или никак: обе строки окон с процентом и сбросом (`0% used` без сброса — окно не начато).
- Опрос продолжается, только если ответ прямо говорит `num_turns: 0` и `total_cost_usd: 0`, иначе выключается до перезапуска. Нечитаемый ответ или выключенный опрос страница показывает баннером (`UsageBanner`).
- Пока окно выбрано, следующая задача не запускается: цепочка ждёт сброса (`limitUntil`) и продолжает сама.
